# DonApo

A prototype for converting an events-business description into a reviewable operating blueprint.

[DonApo at Burrito’s Labs](https://burritoslabs.com/catalogue/donapo/)

## Technology

TypeScript, Next.js, React, PostgreSQL and optional AI-assisted intake.

## Architecture

The system separates transcript review, structured blueprint proposals and a rules-based demonstration for quotes and availability.

## Product behavior

The studio preview uses a sample events business and demonstrates a simulated workflow.
